# iFITS Support

Need help, found a bug, or have an idea? 

- **Report a bug or request a feature:** [GitHub Issues](https://github.com/GalagaBits/iFITS/issues)
- **Email:** dealderod@gmail.com

When reporting a bug, please include your iPad model, your iPadOS version, the iFITS version (shown in iFITS › ••• › Settings) and, if you can, the FITS file or a link to it.

## Common questions

**Which files can iFITS open?**
FITS files with the `.fits` extension: 2-D images and 3-D data cubes.

**Where are my annotations and regions saved?**
Inside the FITS file you opened. Autosave can be turned off in ••• › Settings.

**Why does iFITS ask for the camera?**
Only to place a data cube in your room in AR mode. Nothing is recorded or sent. See the [Privacy Policy](../privacy/).

**Which iPads are supported?**
iPads that run iPadOS 26 or later.
